# 🍱 성수 메뉴픽

성수 점심·회식 맛집 리스트 + 랜덤 뽑기 PWA. 빌드 없는 정적 파일이라 GitHub Pages에 그대로 올리면 된다.

## 기능
- 점심 / 회식 / 안가본곳 / 즐겨찾기 탭, 음식 종류 필터, 검색, 정렬
- 🎲 랜덤 뽑기: 현재 필터 기준, 최근 3일 내 간 곳 제외 옵션, 별점 높은 곳 가중치
- ✅ 오늘 방문 기록 → "n일 전 방문" 표시, 오래 안 간 순 정렬
- ⭐ 즐겨찾기, 별점, 메모, 가게 추가/수정/삭제
- 🗺️ 네이버 지도 검색 바로가기
- 오프라인 동작, 홈 화면에 설치
- 백업 파일 내보내기/불러오기 (데이터는 기기 브라우저에 저장)

## 배포 (GitHub Pages)
1. GitHub에서 새 저장소 생성 (예: `menupick`)
2. 푸시
   ```bash
   git remote add origin https://github.com/<아이디>/menupick.git
   git push -u origin main
   ```
3. 저장소 **Settings → Pages → Branch: `main` / `(root)`** 저장
4. 1~2분 뒤 `https://<아이디>.github.io/menupick/` 접속

## 휴대폰에 설치
- **아이폰(Safari)**: 공유 버튼 → 홈 화면에 추가
- **안드로이드(Chrome)**: 메뉴 ⋮ → 홈 화면에 추가 / 앱 설치

## 목록 수정
- 앱에서 바로 추가/수정하면 그 기기에만 저장된다.
- 모든 기기에 반영하려면 `data.js`의 `DEFAULT_RESTAURANTS`를 고치고 푸시한 뒤, 앱 설정에서 **"기본 목록의 새 가게 추가하기"**를 누른다 (기존 별점·메모는 유지).
- 파일을 바꿔 배포할 때 `sw.js`의 `CACHE` 버전을 올리면 캐시가 확실히 갱신된다.
